# Contribute

Researchers can add a predictor, an information source or a selector independently. Open an issue describing the scientific question, source provenance, units, training-data overlap, compute assumptions and intended evaluation. Then add an adapter plus tests for ID order, budget, duplicate selection, label visibility, deterministic seeds and unavailable actions. Keep dependency-heavy tests opt-in.

Do not upload private sequences, credentials, reserved outcomes or unpublished third-party measurements without permission. A new benchmark configuration must be versioned before evaluation; report failed attempts alongside successful ones. Do not tune a model on full-truth replay scores and call its evaluation blinded.

Contributions are accepted under Apache-2.0 for original code. Third-party data retain their own terms. Authorship is determined by actual scholarly contributions, not automatically by repository commits or AI output.
